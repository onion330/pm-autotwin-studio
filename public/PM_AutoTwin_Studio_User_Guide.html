Before You Start

PM AutoTwin Studio optimizes 3D assets for simulation and digital-twin environments. A recent update added new screens for fine-tuning how an asset is optimized and exported.

The defaults are built to give good results even if you never touch an advanced setting. Each section below notes when, and why, you might want to change one.

STEP 1

Importing an Asset

Open Opt mode from the icon rail on the left and start a new asset — the window below appears. There are two ways to bring in an asset.

Select Asset Source — choose Upload File or Project Assets
  • Upload File — upload a local file straight from your computer.
  • Project Assets — pick from assets you've already uploaded or stored in the cloud. The first time you use it, one sample file is included by default, and every file you upload afterward is added here.
Tip

If you're planning to test the same file multiple times, reuse the version saved in Project Assets instead of re-uploading it from your computer each time — it's faster.

1-1. CAD Files (STEP/IGES) — Choosing Tessellation Quality

STEP and IGES files aren't made of triangles (polygons) — they're mathematical surface data. When you import one, a window opens automatically to decide how finely those surfaces get divided into triangles.

Select CAD Conversion Quality — appears automatically when you import a STEP or IGES file

A finer setting (Ultra Quality) keeps the shape more accurate but increases polygon count and file size; a coarser one (Mobile) is lighter but curved surfaces can look noticeably distorted. You can always reduce the polygon count later in the optimization step, so choose here based on the shape accuracy you actually need right now.

  • Ultra Quality — divides curved surfaces most finely. For precise inspection and measurement; the largest polygon count and file size. (Linear 0.01 / Angular 0.1)
  • Standard (default) — a balanced default between accuracy and size. Suitable for most shape reviews. (Linear 0.1 / Angular 0.1)
  • Lightweight — fewer polygons for faster loading. Curved surfaces may look slightly faceted. (Linear 0.5 / Angular 1)
  • Mobile — the lightest setting, for web and mobile previews; curved surfaces are noticeably distorted. (Linear 1 / Angular 5)
  • Custom — set the linear and angular deflection yourself to fine-tune accuracy.
  • Saved Presets — save and reuse a preset tuned to a CAD source tool you use often, such as SolidWorks.
  • Merge duplicate vertices — merges vertices that sit at the same position, roughly halving the vertex count. Normals are dropped in exchange, so curved surfaces can look faceted; shape and polygon count stay the same.
  • Use these settings automatically for future CAD uploads — when on, STEP/IGES uploads skip this dialog and convert with the selected values right away. You can turn it off any time under Settings > Tessellation.
Tip

If you know which CAD tool exported the file, check Saved Presets first. The SolidWorks preset, for example, is tuned to SolidWorks' own STL-export defaults and gives the result closest to the original.

STEP 2

Running an Optimization

Once an asset is loaded, the left panel lets you configure and run the optimization directly.

Optimization panel — reduction level, output format, estimated cost, run button
  • AI Recommended Ratio — shows the reduction ratio the AI recommends for this asset (62% in the example above).
  • Reduction Level — lets you set the actual reduction ratio with a slider. Higher values remove more vertices but can affect quality.
  • Output Format — choose your output format from FBX, OBJ, STL, GLB, USD (Beta), or PLY (Beta).
  • Estimated Cost — shows the credits this run is expected to use. The number updates as you change settings, so it's worth checking before you run.
  • Run Optimization — starts the optimization with the settings you've chosen.

Optimization Goal (Beta) — when to turn it on

Optimization Goal is off by default, and leaving it off is enough for most cases. Turn it on and you can choose one of two priority modes.

Optimization Goal turned on — choosing Quality Priority or Compression Priority
  • Quality Priority — optimizes only as far as the shape holds up, so the actual reduction can end up lower than the level you set. Works best on models with a low vertex count.
  • Compression Priority — optimizes to hit the reduction level you set. It holds to that target precisely, but the shape can become distorted in the process. Think of it as the counterpart to Quality Priority.
Caution

Optimization Goal is currently a beta feature. Turning it on can slow processing down: Quality Priority may undershoot your target ratio, and Compression Priority hits the target at the cost of possible shape distortion. Unless you have a specific reason, we recommend running with the default (off) first and only turning it on to compare if the result falls short.

STEP 3

Reviewing and Downloading Your Result

Once the optimization finishes, two buttons appear in the bottom-right corner of the screen.

The buttons that appear bottom-right once an optimization completes
  • Download Asset — downloads the optimized file straight to your computer.
  • Save to Asset — saves the result to Project Assets, so you can load it again later or reuse it as the input for another optimization.
Tip

If you're planning to compare several settings on the same file, save each result with Save to Asset instead of downloading every time — it's easier to compare them from the History tab afterward.

STEP 4

Selecting Parts with the Hierarchy

The Hierarchy tab shows the full object tree that makes up your asset.

Hierarchy tab — object tree, search, and vertex-count filter
  • Search objects — search for a specific part by name.
  • Checkboxes — select individual parts directly in the tree.
  • Select by Vertex Count — filter parts by a vertex-count range with the slider, for example to isolate the heaviest parts of the model.
Current Limitation

You can select specific parts and run a partial optimization, but the result view doesn't yet reflect that partial result — it still shows the Original. The partial-selection optimization itself runs correctly; showing its result in this view is a planned improvement.

STEP 5

Reviewing History

The History tab lists every optimization run you've made so far. Select any entry to jump straight back to that result and review it again — useful when you've tested several settings and want to compare outcomes.

STEP 6

Choosing the Right Mode

Three modes are available at the top of the screen. Pick the one that matches your file size and how many assets you're processing.

Mode tabs — Single Asset / Large Asset / Multiple Assets
  • Single Asset — the default mode: load and process one asset directly in the browser.
  • Large Asset — the web viewer has memory limits, so files over roughly 100MB can lag or fail to open. For files that size, use Large Asset mode, or use the desktop viewer that downloads automatically at this point.
  • Multiple Assets — a batch mode that registers several assets at once and processes them in sequence under the same settings.
Multiple Assets — batch queue, supported formats, batch settings, and Job History
  • Current Batch Queue — add the assets you want processed here. It supports FBX, OBJ, STL, GLTF/GLB, PLY, and STP/STEP, so CAD files can be batched too.
  • Optimization Settings — the Target Reduction slider, the Plant Std / Mobile / Balanced presets, and the Min Vertex Count threshold apply the same settings to every asset in the queue.
  • Start All — runs every asset in the queue in one go.
  • Job History — shows completed batch runs on the right side of the screen (for example, "Optimized 3 Assets, 3/3, Target: 50%").
STEP 7

AI Settings — Vertex Importance Optimization (Beta)

Settings > AI Settings is where you turn the AI features used during optimization on or off.

Settings > AI Settings — the AI Vertex Importance Optimization toggle

It's off by default. Turn it on and, during optimization, the AI analyzes the model's important vertices and reduces polygons while preserving its shape.

Beta Feature

AI Vertex Importance Optimization is currently in beta. The AI analyzes and optimizes while preserving shape, but the resulting quality and actual reduction ratio can differ from expectations depending on the model, and the added analysis step can make optimization take longer than usual.

Tuned for Machine Parts

The current model is trained mainly on machine-part data, so it performs best on mechanical part shapes. It offers relatively less benefit on organic shapes such as characters or terrain.

STEP 8

Checking Your Account and Credits

Settings > Account Settings is where you manage your profile — email, display name, and organization. Clicking the account icon in the top-right corner opens a dropdown with the same information at a glance.

Settings > Account Settings — profile information and the account dropdown (plan, credits, storage)
  • Plan — shows your current plan (Pro Plan, for example).
  • Credits — shows your credit balance. Credits are spent every time you run an optimization (see Estimated Cost in step 2), and this icon shows the balance in real time.
  • Storage — shows your storage usage (for example, 746.7MB / 20GB).
  • My Organization — switch between organizations here if you belong to more than one.

Frequently Asked Questions

Which options should I turn on the first time I use it?

Leave both Optimization Goal and AI Vertex Importance Optimization at their default (off) and run once to see the result first. For assets where shape preservation really matters — machine parts, for example — try turning on AI Vertex Importance Optimization and compare.

A window popped up when I uploaded a STEP/IGES file — what is it?

CAD files are surface data, so converting them into a triangle mesh (tessellation) requires choosing an accuracy level first. Standard, the default, is enough for most cases, and you can reduce the polygon count further in the optimization step afterward.

How do I get my optimized result?

Once the optimization finishes, Download Asset (download immediately) and Save to Asset (save to Project Assets) appear in the bottom-right corner of the screen.

Where do I check my credit balance?

Click the account icon in the top-right corner to see your credit balance, plan, and storage usage.

What if my file is over 100MB?

Use Large Asset mode, or the desktop viewer that downloads automatically at that point.

I only want to optimize a specific part.

You can select the parts you want in the Hierarchy tab and run a partial optimization. Right now the result view still shows the original, a limitation we plan to fix in a future update.
